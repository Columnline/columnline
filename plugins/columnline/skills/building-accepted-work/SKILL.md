# Hand accepted work to its builder

## In plain English

Execute only authorized scope. Follow the stage boundary below and leave the next person a clear, truthful handoff.

Read [the overarching workflow](../driving-work-end-to-end/SKILL.md) and [shared authority/evidence rules](../driving-work-end-to-end/reference/system.md) first.

## Entry

Accepted scope where required, actual builder pickup and canonical work, source context and existing commitments.

## Work and permitted actions

Execute only authorized scope. Keep actual work and blockers honest; name dependencies instead of inventing dates or blanket reassignments. Preserve the linked parent and existing approval. Keep engineering details private when requested. Verify the result before recording delivery; a status change or a prepared PDF alone does not prove completion.

## Exit and exceptions

Verified delivery evidence and handoff for the delivery-acceptance package. Research-only work may reach Delivered directly without a build cycle.

Record actual friction and source evidence for a narrow reviewed correction. Never silently change stage semantics, approval policy, channel authority or enablement.
